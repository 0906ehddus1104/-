종목: 이름을 자유롭게 입력해 추가·삭제함. 비어 있을 때는 예시 종목과 루틴을 넣어보는 버튼이 있음.
루틴: 루틴 이름(예: 하체A)을 만든 뒤 "종목 고르기"에서 누른 순서대로 종목이 담김.
기록: 달력(월요일 시작)에서 날짜를 고르고 위쪽 루틴을 누르면 종목이 뜸. 종목을 누르면 세트 수를 +/−로 정하고 세트별 kg과 반복 횟수를 입력함.
추세: 종목을 누르면 날짜별 총합 무게(세트별 kg × 횟수의 합) 그래프가 나옴. 몸무게는 날짜와 kg을 입력하면 별도 그래프로 표시됨

기록은 계정에 저장되어 다른 기기에서도 이어짐. 서버 연결이 안 되면 "이 기기에만 저장됨"으로 표시되고 해당 브라우저에만 남음.
종목을 삭제하면 그 종목의 과거 기록은 추세에서 보이지 않게 됨.
무게를 0kg으로 입력하는 맨몸 운동은 총합 무게가 0으로 계산됨.
